# Локальная проверка голоса Алины в ECHO

Текущий шаг подключает принятый Canvas-аватар и OmniVoice к существующему WebRTC-интерфейсу. Микрофон, автоматическое определение речи и кнопки остаются прежними. Realtime принимает речь без фиксированного входного языка; педагогические инструкции по-прежнему задают украинский язык ответа. Не гарантируется одинаковое качество понимания всех языков.

## Запуск на Windows

Сначала остановите старый `alina-lips-test.py` через Ctrl+C, чтобы освободить GPU.

Первый PowerShell, из корня репозитория ECHO Education (`<project-root>`):

```powershell
& "$HOME\alina-voice-test\.venv\Scripts\python.exe" .\local-voice\server.py --voice-dir "$HOME\alina-voice-test\alina-lips-test"
```

Дождитесь `Alina voice ready at http://127.0.0.1:8006`.

Второй PowerShell, из той же папки:

```powershell
$env:OPENAI_API_KEY="ваш-ключ"
.\node_modules\.bin\next.cmd dev -p 3100
```

Если ключ уже установлен в этом терминале, повторно задавать его не нужно.
Откройте http://localhost:3100, нажмите «Почати» и разрешите микрофон.
Не запускайте страницу 8005: это предыдущий отдельный тест.
Новые npm-пакеты и новый Python не нужны. Используется прежнее окружение OmniVoice/FastAPI/uvicorn/soundfile/torch.

## Что проверить

1. Задать вопрос по-украински, затем по-русски или на другом знакомом языке. Проверить смысл ответа, а не обещание универсального распознавания.
2. Дождаться голоса Алины и проверить губы, цвет и переход раздумия → речь.
3. Перебить во время речи. Голос должен остановиться, рот закрыться, старый ответ не должен возобновиться.
4. Перебить, пока ещё идёт синтез. Поздний результат должен быть отброшен.
5. Проверить mute/unmute, «Завершити», повторный «Почати».

## Изменённые файлы и поведение

- `app/page.js`: подключение локальной озвучки к событиям существующей Realtime-сессии, сохранение текущих кнопок.
- `app/api/realtime-token/route.js`: текстовый выход Realtime вместо встроенного голоса. Модель и teacher prompt прежние.
- `app/api/alina/synthesize/route.js`: health, синтез и отмена через loopback 8006; постоянный OpenAI-ключ остаётся серверным.
- `app/lib/alina-voice.js`: владение ответом, отмена, отбрасывание поздних данных, Web Audio.
- `app/lib/mouth-player.js`, `app/components/TeacherAvatar.js`, `app/globals.css`: принятый единый Canvas для видео и губ.
- `public/teachers/alina/live/`: принятые idle, формы рта, tracking и thinking без логотипа.
- `local-voice/server.py`: OmniVoice 32 шага, прежний референс, новые Rhubarb cues для каждого ответа.
- `tests/alina-voice.test.mjs`: отмена при синтезе/переходе/воспроизведении и защита от старых ответов.
- `.gitignore`: исключение окружения, сборки, ключей и Python cache.

Готовый короткий ответ озвучивается целиком, чтобы не обрезать интонацию. Это не потоковый PCM: начало голоса ждёт завершения текста, синтеза и расчёта движений рта.
При перебивании останавливается воспроизведение и отменяется ожидающий результат. Уже запущенный GPU-проход может завершиться в фоне; его результат не воспроизводится.

Ограничение этого шага: Realtime хранит созданный текст ответа целиком, даже если ребёнок услышал только часть до перебивания. Пословная синхронизация услышанной части с историей не добавлена.

Это локальный запуск: Next.js и Python работают на одном компьютере. Развёртывание на Vercel с доступом к GPU-сервису этим шагом не решается. Речь ребёнка не записывается приложением на диск; временный WAV ответа для Rhubarb удаляется после обработки.

## Проверки

Пройдены lint, production build и три теста клиентской отмены. Отдельного typecheck в JavaScript-проекте нет; проверка сборки Next завершена.
Python: проверены health, входная валидация, отмена до запуска и во время синтеза, WAV и настоящий Rhubarb на тестовом аудио.
Chromium: desktop/mobile, mute/unmute, Next proxy → тестовый CPU-синтез → Rhubarb → Canvas, перебивание, игнорирование старого ответа, end/restart; JS-ошибок нет.
Настоящие OpenAI WebRTC и OmniVoice/CUDA в этой среде не запускались; реальная задержка не измерена.

Официальный контракт текстовых ответов Realtime: https://developers.openai.com/api/docs/guides/realtime-conversations
